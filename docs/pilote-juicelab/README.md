retrouvées sur Lexar. Les originaux ne sont pas republiés. Les pages et leurs
empreintes figurent dans l'index et [SOURCES_COURS.json](SOURCES_COURS.json).

Deux blocs de quatre heures sont proposés. Les treize défis sont planifiés ;
leur résolution par chacun n'est pas garantie. La disponibilité des défis doit
être contrôlée sur les instances natives de classe. La reprise conserve les
anciens travaux et ne promet pas de migration automatique des données.
