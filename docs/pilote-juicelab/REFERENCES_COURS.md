# Références des cours pour préparer JuiceLab

Sources examinées le 14 novembre 2026, sur la clé Lexar effectivement montée.
Les fichiers sont conservés à leur emplacement d'origine ; les supports complets
ne sont pas ajoutés au dépôt. La sélection ne vaut pas validation globale des cours.

La sélection `cour cyber/fr` ne contient pas de fichier numéroté8. Dans le dossier
voisin `cours`, `8-S1-isi5-man_in_th_middle.pdf` existe (15 pages), ainsi que
`7-S1-isi5-csrf.pdf` (15 pages) et le support XSS (12 pages). Ne pas fusionner ces
numérotations : le cours6 de la série FR est consacré au DDoS, tandis que le PDF6
de l'autre série porte sur XSS. Le titre du support XSS et ses pages3,9,10 ont été
examinés visuellement. Les contenus MITM et CSRF ne sont pas recettés ni intégrés
comme prérequis obligatoires du pilote13 sur la seule base de leurs noms.

Les sessions, les droits sur les objets et les limites de preuve sont expliqués
dans le PowerPoint JuiceLab avec des exemples fictifs et les références OWASP.
Un cours autonome sur ces sujets dans l'ensemble complet de la clé n'est pas
établi ; une recherche limitée aux dossiers cités ne prouve pas son absence.

Précisions transmises au professeur dans le document12 : la séparation structure /
valeurs est le contrat utile du paramétrage ; la précompilation n'est pas posée
comme universelle. Un sel ne rend pas toute recherche impossible. Les contrôles
Windows ne sont pas attribués à l'application web par proximité de vocabulaire.
